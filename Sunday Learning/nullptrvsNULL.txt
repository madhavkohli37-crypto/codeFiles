if we do char ch=NULL; the char ch will be 0 in terms of ascii value of 0 which is '\0'
so ch='\0' if we say char ch=NULL;
hence if we do cout<<x<<endl; then there will be no output because cout with a char works as printing a string format and it prints characters untill it doesn't
